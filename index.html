Instalação do Meta Pixel (Passo a Passo)

  1. Criar Pixel: No Gerenciador de Eventos do Meta, clique em “Conectar fontes de dados” → “Web” → “Pixel do Meta”. Nomeie como "Mondez Pixel".
  2. Instalar no site: Copie o código base e cole entre as tags de todas as páginas. Se usar WordPress, use plugin "Meta Pixel".
  3. Configurar eventos: Adicione eventos padrão como "ViewContent" (quando visualizar produto), "AddToCart" e "Purchase". Use a ferramenta "Configurações de Eventos" do Pixel.
  4. Verificar com Pixel Helper: Instale a extensão do Chrome e verifique se o pixel está disparando corretamente.
  5. Integrar API de Conversões: Para maior precisão, configure a API de Conversões (via Gerenciador de Eventos). Isso melhora a atribuição.
Dica: Crie públicos personalizados com base em quem visitou páginas de produtos específicos para remarketing.

Como criar sua loja no Mercado Livre

  1. Cadastro: Acesse "Vender" no Mercado Livre. Preencha dados da empresa (CNPJ) e conta bancária.
  2. Configurar reputação: Comece vendendo produtos de ticket menor para ganhar as primeiras avaliações positivas.
  3. Anúncios: Escolha entre Clássico (11,5%) ou Premium (16,5%). Para móveis de alto padrão, o Premium oferece parcelamento e mais visibilidade.
  4. Logística: Ative o Mercado Envios e considere o Full para armazenar produtos nos centros de distribuição do ML.
  5. Estratégia de preço: Simule com a calculadora de taxas (disponível no site do Mercado Livre) para garantir margem.
